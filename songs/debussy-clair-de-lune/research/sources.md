# Sources - Clair de lune

- **Mutopia Project, LilyPond edition** -
  <https://www.mutopiaproject.org/ftp/DebussyC/L75/debussy_Ste_Bergamesq_Clair/>
  Source `.ly` and rendered `.mid`. Mutopia's typesetters release their
  engravings into the public domain; Debussy died in 1918, so the music itself
  is public domain.
  Trust: high. Used for **all the notes**. Only the transcription is committed,
  per the repo's copyright rule.

- **MuseTrainer MusicXML library** -
  `musetrainer.github.io/library/scores/Clair_de_lune_-_Claude_Debussy.mxl`
  Used earlier for `examples/clair-de-lune.play.yaml`, and here only as an
  independent check (see `report.md`).
  Trust: high as a second opinion - a different engraving lineage.
