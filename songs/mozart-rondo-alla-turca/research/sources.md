# Sources

- Mutopia Project, piece page for Sonate Opus KV 331, Rondo Alla Turca by
  W. A. Mozart: https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=108
  Licence on the page: Public Domain. Source: IMSLP. Typesetters: Rune Zedeler
  and Chris Sawer. I read the page on 2026-11-17.
- The zipped LilyPond files of that edition:
  https://www.mutopiaproject.org/ftp/MozartWA/KV331/KV331_3_RondoAllaTurca/KV331_3_RondoAllaTurca-lys.zip
  The notes file is the source of this score: pitches, rhythms, repeats,
  endings and dynamics. The tempo is not in it.
- The edition's MIDI file from the same folder, used only to check the score
  note for note. All files were kept in a temporary folder and deleted
  afterwards. None is in this repo.
