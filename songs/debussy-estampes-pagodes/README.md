# Claude Debussy — Estampes, L. 100: I. Pagodes

Opening movement of Debussy's *Estampes* (1903), inspired by Javanese Gamelan music heard at the 1889 Paris World Exposition.
Built upon pentatonic scales (B, C#, D#, F#, G#) and multi-layered bell/gong textures.

- **Key**: B major (Pentatonic)
- **Tempo**: 64 bpm (Modérément animé)
- **Scoring**: 4 piano layers (gong bass, ostinato mid, bell treble, pentatonic melody)
