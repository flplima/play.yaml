# Sources — BWV 528

- **Mutopia Project, LilyPond edition** —
  <https://www.mutopiaproject.org/ftp/BachJS/BWV528/SonataIV/>
  `SonataIV-lys/Andante.ly` (source) and `SonataIV-mids.zip` (rendered MIDI).
  Public domain: Mutopia's typesetters release their engravings outright, and
  Bach has been public domain since 1750. The `.ly` uses German note names.
  Trust: high. Used for **all the notes**; only the transcription is committed.

- The movement's identity, meter and key were confirmed by matching the
  LilyPond source's opening line against the MIDI's top voice (see
  `report.md`), rather than by trusting the file numbering.
