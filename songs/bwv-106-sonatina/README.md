# J.S. Bach — BWV 106: I. Sonatina

Opening instrumental movement of Cantata BWV 106 *Gottes Zeit ist die allerbeste Zeit* (Actus Tragicus).
Scored for 2 Recorders, 2 Viole da Gamba, and Continuo.

- **Key**: C minor / E-flat major
- **Tempo**: 54 bpm (Molto adagio)
- **Scoring**: 2 flutes (recorders), 2 cellos (gambas), organ (continuo)
