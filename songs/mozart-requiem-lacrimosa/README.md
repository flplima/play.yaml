# W.A. Mozart — Requiem K. 626: Lacrimosa

The iconic *Lacrimosa dies illa* movement from Mozart's Requiem in D minor, K. 626.
Features the famous weeping violin suspensions in 12/8 meter.

- **Key**: D minor
- **Meter**: 12/8
- **Tempo**: 48 bpm (Larghetto)
- **Scoring**: Violins, 4-part choir, Continuo
