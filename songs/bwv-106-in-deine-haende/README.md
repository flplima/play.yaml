# J.S. Bach — BWV 106: 3a. In deine Hände befehl ich meinen Geist

The alto aria that opens the second half of the *Actus tragicus* — the New
Testament's answer to the death of the first half. Psalm 31:5: *"Into your
hands I commend my spirit; you have redeemed me, Lord, faithful God."*

**24 bars, B-flat minor** — the darkest key in the cantata — ♩=60, common time.

- **Scoring**: **alto and continuo, nothing else.** Reference works commonly
  list this aria as "alto with two viole da gamba"; in the score the gambas do
  not play a note until bar 39, which is inside 3b. The alto itself does not
  enter until bar 3.
- **Casting**: alto → `strings` (the DSL has no vocal sample), continuo →
  `keys`.
- **Verified**: 463 source notes → 463 in the score, 0 missing, 0 extra,
  0 moved.

## Where the notes come from

Imported with `play-yaml-import --verify` from Ramon Casadesus-Masanell's
engraving of the complete cantata (IMSLP #752782, CC BY-NC-SA 4.0, 2021),
whose MusicXML/MIDI export is mechanically faithful to the edition. Bach's
notes are public domain; the engraving is not, so no file from it is
committed — only this transcription.

The full research report, the movement table, the section boundaries and the
two corrections this work makes to the reference literature live in
[`../bwv-106-sonatina/research/report.md`](../bwv-106-sonatina/research/report.md).
