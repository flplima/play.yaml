# Sources

- Mutopia Project, piece page for In the Hall of the Mountain King by
  E. Grieg: https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1888
  Licence on the page: Public Domain. Source edition: The University Society,
  1918. Typesetter: Coyau. I read the page on 2026-11-17.
- The edition's LilyPond file and MIDI file, linked from that page. I used the
  MIDI for the note import and the LilyPond file for the key, the meter, the
  tempo markings and the dynamics. Both were kept in a temporary folder and
  deleted afterwards. Neither is in this repo.
- The page points to an IMSLP scan of the print. I did not open it.
- Bars 74 to 88 (the grace note slides), the "sempre stretto sin al fine"
  marking and every dynamic mark were checked again against the LilyPond file.
