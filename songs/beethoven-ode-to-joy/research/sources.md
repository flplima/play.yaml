# Sources: Ode to Joy (Beethoven / Schiller)

Nothing from these sources is stored in the repo. The scans and the MIDI file
were used in a scratch folder and deleted.

- **Beethoven, Symphonie Nr. 9, first edition of the full score (Schott,
  Mainz, 1826)**, scan on Wikimedia Commons:
  <https://commons.wikimedia.org/wiki/File:Beethoven_-_Symphonie_Nr.9,_Partiturerstausgabe_1826.pdf>.
  Licence: public domain (Commons marks it so; the composer died in 1827 and
  the print is from 1826). **Primary source** for the baritone's theme,
  rhythms and German underlay, on printed pages 113 to 115. It is a scan, so
  small details (see bar 14 in the README) are hard to read.

- **Mutopia Project, "Ode to Joy"**,
  <https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=528>. A SATB hymn
  setting in G, typeset by Peter Chubb. Licence: public domain, as stated on
  the page. Used only to cross-check the pitches (moved a fifth down). It is
  not the symphony, so it has no tied syncopation in bar 12.

- **IMSLP, Symphony No. 9, Op. 125**,
  <https://imslp.org/wiki/Symphony_No.9,_Op.125_(Beethoven,_Ludwig_van)>.
  Used to find which public domain editions exist (Breitkopf & Härtel, Schott,
  Litolff and others). Its file server asked for a bot check, so I did not
  download from it and used the Wikimedia scan instead.

- **Schiller, *An die Freude***. The first stanza is public domain (Schiller
  died in 1805). The words in the file were read off the 1826 print's
  underlay and put into modern spelling.
